# 安卓手机 PWA 验证清单

## 前置条件
- [ ] 电脑已运行 `tools\install-server.ps1`（显示 IP 和端口）
- [ ] 手机和电脑连接**同一个 WiFi**（检查手机 WiFi 名称和电脑网络是否一致）
- [ ] 手机已安装 Chrome 浏览器（华为应用市场/小米商店可下载）

## 步骤 1：访问引导页
- [ ] 手机 Chrome 打开 `http://172.192.151.191:18765/`
- [ ] 能看到"📲 安装「记账本」到手机"标题
- [ ] 能看到 4 个步骤卡片和说明

## 步骤 2：下载并安装 CA 证书
- [ ] 点击"① 下载 CA 证书"按钮
- [ ] 下载完成通知栏显示 RootCA.cer
- [ ] 进入手机设置 → 搜索"证书"或按品牌路径找到"安装证书"
- [ ] 选择"CA 证书" → 从下载文件夹选中 RootCA.cer
- [ ] 安装时如提示"网络可能被监控"，点"仍然安装"
- [ ] 如提示需要锁屏密码，先设置数字 PIN（装完可改回图案/指纹）

## 步骤 3：打开 HTTPS 应用
- [ ] **杀掉 Chrome 重新打开**（从最近任务划掉）
- [ ] 点击引导页"② 打开记账本（加密连接）"
- [ ] 地址栏显示 `https://172.192.151.191:18766/`
- [ ] **无红色安全警告**（地址栏左侧显示锁图标）
- [ ] 能看到记账应用首页（初始为空，显示 9 个分类图标）

## 步骤 4：添加到桌面
- [ ] Chrome 右上角 ⋮ 菜单 →「安装应用」或「添加到主屏幕」
- [ ] 确认添加，桌面出现「记账本」图标
- [ ] 图标显示为蓝底白色圆环 ¥ 符号

## 步骤 5：验证离线可用
- [ ] 关闭电脑上的安装服务窗口（Ctrl+C 或 ×）
- [ ] 手机开启**飞行模式**（或断开 WiFi）
- [ ] 从桌面图标打开「记账本」
- [ ] 应用正常打开，无网络错误提示
- [ ] 首页显示"2026年9月 · 总支出 ¥0"

## 步骤 6：验证记账功能
- [ ] 点击底部「＋」→ 选择「餐食」
- [ ] 输入金额 35.5，选择"午餐"，店名填"测试面馆"
- [ ] 保存后首页圆盘显示 ¥35.5
- [ ] 分类列表显示"餐食 ¥35.5"
- [ ] 关闭应用重开，数据仍在

## 步骤 7：验证独立账本
- [ ] 电脑浏览器打开 `index.html`，首页显示旧数据（如有）
- [ ] 手机显示 ¥35.5（新记录）
- [ ] 两者数据**互不相通**，确认是独立账本

## 步骤 8：验证备份（可选）
- [ ] 手机应用 →「我的」→「导出备份」
- [ ] 下载文件夹出现 JSON 文件
- [ ] 清理 Chrome 数据前可用此文件恢复

## 常见问题排查
| 问题 | 解决方案 |
|---|---|
| 手机打不开引导页 | 检查 WiFi 是否同一网络；检查电脑防火墙是否允许 PowerShell |
| 证书安装后仍有警告 | 杀掉 Chrome 重开；确认装的是"CA 证书"不是"用户证书" |
| 添加桌面后离线打不开 | 先正常访问一次 HTTPS 页面，等 3 秒再添加 |
| 换 WiFi 后打不开 | 电脑 IP 变了，重新运行 `install-server.ps1` |

## 验证完成标准
全部步骤通过，且满足：
1. 手机桌面有「记账本」图标
2. 飞行模式下能正常打开和记账
3. 数据保存在手机本地，与电脑独立
4. 无安全警告、无报错
