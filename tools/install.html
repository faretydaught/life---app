📲 安装「记账本」到手机

全程只在你家里的网络中进行，不会连接互联网。
⚠️ 安装前必读
  1. 手机必须和电脑连同一个 WiFi；
  2. 电脑上的安装服务窗口在添加到桌面之前不要关闭；
  3. 如果电脑上弹出"Windows 安全警报"问是否允许 PowerShell 访问网络，请点「允许」；
  4. 手机上是一本独立的新账本，和电脑上的数据互不相通。
1下载并安装安全证书
① 下载 CA 证书
下载后需要手动安装证书（Chrome 不会自动安装）。
不同品牌手机的路径不一样，请按你的手机品牌查找：
小米/Redmi设置 → 密码与安全 → 系统安全 → 加密与凭据 → 从存储设备安装 → CA 证书
华为/荣耀设置 → 安全 → 更多安全设置 → 加密与凭据 → 从存储设备安装 → CA 证书
（或在设置顶部搜索"证书"）
OPPO/realme设置 → 安全 → 安装证书 → CA 证书
vivo/iQOO设置 → 安全与隐私 → 更多安全设置 → 从手机存储安装 → CA 证书
三星设置 → 生物识别和安全 → 其他安全设置 → 安装证书 → CA 证书
一加设置 → 安全和锁屏 → 加密与凭据 → 安装证书 → CA 证书
卡住常见问题：
  1. 如果系统提示"需要先设置锁屏密码"，去设置一个数字 PIN 码（装完证书可以改回图案/指纹）；
  2. 安装时若弹出"您的网络可能受到监控"，这是正常提示，点「仍然安装」；
  3. 装完后杀掉 Chrome 重新打开（从最近任务里划掉 Chrome），否则可能仍显示安全警告。
2打开记账应用
② 打开记账本（加密连接）
打开后应没有任何安全警告，能看到记账首页（初始为空是正常的——手机是一本独立的新账）。
如果仍有红色安全警告，说明第 1 步证书没装好，请回去重装。
3添加到手机桌面
  1. 点 Chrome 右上角 「⋮」 菜单；
  2. 选择 「安装应用」 或 「添加到主屏幕」，按确认；
  3. 手机桌面上会出现「记账本」图标。
没有谷歌服务的手机，菜单里可能只显示「添加到主屏幕」——这是正常的，功能完全一样。
4验证离线可用
  1. 现在可以关掉电脑上的安装服务窗口了（Ctrl+C 或直接 × 掉）；
  2. 手机断开 WiFi / 开飞行模式；
  3. 从桌面图标打开「记账本」——应能正常打开、正常记账；
  4. 记一笔后关掉重开，数据仍在，即安装成功。
🔧 如果打不开怎么办？
  1. 手机访问不了引导页：确认手机和电脑连的是同一个 WiFi（不是手机流量）；检查电脑上有没有弹出 Windows 防火墙弹窗并点了"拒绝"；某些公共/公司 WiFi 开了"AP 隔离"（设备间不能互访），此时可以改用手机开热点让电脑连上；
  2. 证书装好了仍有安全警告：杀掉 Chrome 重新打开；确认安装的是CA 证书而不是用户证书；
  3. HTTPS 能打开但添加到桌面后离线打不开：说明 Service Worker 没缓存成功。先通过浏览器正常打开一次 HTTPS 页面，等几秒再添加；
  4. 换 WiFi / 路由器重启后打不开：电脑 IP 变了，证书里的 IP 也变了。回到电脑重新运行 tools\install-server.ps1 即可重新生成证书和启动服务。
ℹ️ 重要提醒
清理 Chrome 数据会删除手机账本！ 清理前务必在应用「我的」页导出备份（JSON 文件保存到手机下载目录）。

电脑上无需安装任何额外软件。整个安装工具（证书生成 + HTTP/HTTPS 双端口服务）都是纯 PowerShell 脚本，运行完即可删除，不会常驻后台。
